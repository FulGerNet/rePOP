# reSOT v0.3.2

Windows demo and retail executables and the shared Android APK use version
0.3.2; Android versionCode is 7. Both targets still require the user's supported
Xbox game files. Game content, logs and compiled packages are not committed.

- Fixed rectangular mip chains reaching zero-sized dimensions in SDL Vulkan,
  D3D12 render targets and common blit source calculations. The user confirms
  colored-pixel corruption is resolved on Poco X3 Pro and operation is restored
  on the tested MediaTek/Samsung device. This is device-specific confirmation,
  not certification of all GPUs. The tested mobile CPU-vertex profile remains.
- Restored depthless character shadow casters without reversing the scene-depth
  correction for geometry showing through. The user confirms shadows restored.
- Replaced post-processing quality and the standalone texture-glow switch with
  one **Graphics preset**, on demo/retail and Windows/Android:
  - **Reduced:** 50% auxiliary-effect dimensions, recognized character shadows
    disabled; display/HUD/history buffers and tiny bloom tail remain protected.
  - **Standard:** former High quality, texture glow disabled; new default.
  - **Full:** Standard plus the texture glow effect.
  Debug **Off** remains only in the INI and Windows F7. The normal menu cycles
  Reduced/Standard/Full. Existing High/Mid become Standard, Low becomes Reduced,
  enabled glow becomes Full unless Off was selected. New GraphicsPreset keys
  take precedence. This change does not promise an FPS gain in CPU-bound scenes.
- Added on-demand Android diagnostic ZIP sharing from the launcher version.
  Normal logging remains unchanged. Temporary exports expire automatically;
  the OS does not report reliable send completion. A Samsung export was received;
  real cancellation/cleanup timing still needs handset validation.
- Added offline full-APK v2/v3 verification and current publisher-certificate
  checking before launcher/game initialization. The existing signing identity
  is retained for in-place updates. Modified/re-signed packages are refused;
  temporary read failures offer Retry rather than report modification. Signing
  identity is checked during packaging too. Developer forks need their own pin.
  A repackager can attempt to patch a local verifier; this is not a malware
  scanner or an absolute guarantee against a rewritten app.
- Both launchers check stable GitHub releases asynchronously and offer **Update**
  / **Close** in the launcher's navy/gold/cyan style and display font. Updating
  is optional; network errors never gate startup. Update opens the official
  GitHub release page. No logs/game files/settings are sent. Existing `reSOTv`
  tags and plain `v`/numeric versions are recognized; prereleases are ignored.

Shader checks, 14 native GPU tests, four host/target menu tests, strict update
response/version tests and real Windows popup render/dismissal tests pass.
The production WinHTTP request successfully reads the official latest release.
The actual APK verifier accepts the official APK and rejects changed-content
and different-signer copies across API 29-36 checks. These JVM checks do not
replace an Android-device startup/UI test. New presets and Android popup/input
behavior still need user validation; broader gameplay/GPU coverage is open.
See [VALIDATION.md](../VALIDATION.md) for commands and artifact hashes.
