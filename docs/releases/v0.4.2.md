# reSOT v0.4.2

Windows demo and retail executables and the shared Android APK use version
0.4.2; Android versionCode is 12. Both targets still require the user's supported
Xbox game files. Game content, logs and compiled packages are not committed.

## Retail

- **HD main menu logo.** The low-resolution title logo is replaced on the host
  by an HD image, on D3D11, D3D12, Vulkan and Android. Confirmed by the user.
- **Name keyboard with mouse and touch.** On the profile-name keyboard, pointing
  or tapping only reached letters in the middle, so a name could not be typed.
  The pointer now walks to the row and then along it. Confirmed by the user.
- **Sand tanks stay at the widescreen HUD position.** With many tanks, full
  tanks and forming empty rings went back to the old centred 4:3 position. The
  whole column is now anchored, however long it grows.
- **Vulkan black flashes.** Certain places alternated gameplay with a black
  screen for about half a second. Confirmed fixed by the user on Windows.
- **Farah Room door.** Both leaves of the door are visible again on D3D11
  (confirmed by the user). Not checked on Vulkan, D3D12 or Android.
- **Light halos (candidate).** Halo visibility tests are compared at a slightly
  nearer depth and dim halos are raised. Built, not confirmed: on the last test
  D3D11 still showed no halos and Vulkan only some.
- **Fewer shader hitches on D3D11.** Vertex shaders now compile in the
  background instead of on the GPU thread. No frame-rate gain has been measured.

## Demo

- **HD main menu logo.** The menu logo is replaced by an HD image, keeping the
  game's yellow tint. It stays hidden during play.
- **6201 PrisonA in Special Load Map.** This entry showed the Prince as a head
  only, because its map loads neither his costume nor his set-up. It now loads
  the 08_GP62_E3_Cour map, which has the same areas and both, so the starting
  point can differ from the original entry.
- **Closing E3 clip.** It has no sound because the clip itself has no audio
  track; this is documented and not a bug.

## Both games

- **Vulkan queries are reused again**, removing about 2400 create/destroy pairs
  per second from the driver. This aims at a rare crash in the NVIDIA driver,
  whose cause has not been established.
- **Crash reports** now name the faulting thread and list stack words pointing
  into loaded modules.

## Known issues and what was not checked

The demo's HD logo and its 6201 PrisonA change, and the retail sand tank change,
were built but have not been confirmed in game by the user. The agent did not
run the game. Android was not tested on a device for this release. The Farah
Room gate remains under investigation outside the D3D11 result above. The
issues listed as known in v0.4.1 still apply.

The HD logos are compiled into these executables, but the images and their
generated headers are not in the repository; a build from a clean checkout
draws the games' own logos. See [LICENSING.md](../LICENSING.md) and
[VALIDATION.md](../VALIDATION.md) for commands and results.
