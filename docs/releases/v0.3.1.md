# reSOT v0.3.1

Windows demo and retail executables and the shared Android APK are version
0.3.1; Android uses versionCode 6. Your own supported Xbox game files are
required. Game files and compiled packages are not committed to the repository.

- Corrected depth reconstruction for geometry crossing the camera's eye
  plane. The user confirms the transparent demo bridge is resolved on Android.
- Recognized LowerBath's ARGB halo variant; its correction previously matched
  zero draws. The user confirms the retail lights are resolved on Android.
- Kept every piece of the upgraded retail health-bar outline anchored with
  its fill, including parts that extend beyond the screen centre. Confirmed
  by the user on Android.
- Recognized literal-text popup choices, including Yes/No. Hit testing also
  separates side-by-side choices. Retail save-carousel arrows emit left/right
  input without activating or deleting a save. Windows uses the same bridge
  for mouse clicks.
- Refreshed both launchers: current version at the upper left, reSOT and
  Prince of Persia in Atlantis, The Sands of Time in the regular badge font.
- Included the touch visibility, DXT initialization, vertex precision and
  partial depth-clear corrections recorded in the validation log.

Shader checks, both menu-pointer layouts, touch policy and all 14 native GPU
tests pass. Both Windows targets and the Android release APK build. The
new popup/carousel interactions and launcher presentation are confirmed by
the user on the Android test phone; other GPUs, retail Hourglass Room and full-game visual
accuracy remain outside these checks. See [VALIDATION.md](../VALIDATION.md).
