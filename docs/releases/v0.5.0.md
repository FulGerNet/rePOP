# reSOT v0.5.0

**European Xbox ROM support is here, together with German and Italian.**
The PAL European retail disc is now recognised by the Windows and Android
launchers and can be installed directly from ISO. No manual replacement of
`default.xbe` or rearrangement of the disc files is required.

## European retail disc

- **EU disc recognition on Windows and Android.** Android now enables
  Start Game for the known European edition. Both hosts use the checked
  NTSC runtime with the EU disc's data, keeping the original EU files intact.
- **Fixed the EU startup's dirty/damaged-disc error.** Movies are now found
  in the European disc's `VIDEO/30fps` and `VIDEO/25fps` directories. The
  original flat movie paths remain supported; genuine read errors are
  still reported by the game.
- **Windows keeps the selected installation.** An explicit or remembered
  EU folder takes precedence over an automatically detected USA folder.
  Other identified disc revisions can be attempted with a compatibility
  notice. Android continues to reject unknown executable revisions.

## Five game languages

- **Deutsch and Italiano added** alongside English, French and Spanish in
  **reSOT Options > Language**, on Windows and Android.
- **All five choices always remain visible**, including with the USA disc.
  When German/Italian sound banks are absent, the game uses English for
  that run while retaining the selected preference.
- **Language changes apply on the next start.** The selection is saved
  immediately. The startup language mapping now activates the EU language
  data rather than silently reverting German and Italian to English.
- The demo continues to use English.

## Windows cursor and version

- A light-halo cursor, derived locally from the game's own BF, appears in
  the Windows launcher, native menus and F7 options. Android retains its
  touch controls.
- Windows executables and the Android APK report **0.5.0**; Android
  versionCode is **15**.

## Validation and remaining checks

Windows demo/retail builds, the Android release build, shader checks and
the loader/language preference tests passed. On Windows, EU startup, movies,
menus and an existing cave-area save were checked; the Italian menu was
seen, and German startup loaded its language banks and rendered the initial
Prince scene. USA fallback with Italian selected was also checked.

**Android was built and its runtime image verified, but was not run on a
device. A full EU playthrough and exhaustive language/audio checks remain
pending.** Commands and observed results are in
[VALIDATION.md](../VALIDATION.md).

Local APK builds now embed the owner's SHA-256-checked NTSC runtime image,
as Windows executables already do. This image and the disc assets are
game-owned, excluded from the repository and outside reSOT's MIT licence;
see [LICENSING.md](../LICENSING.md).
