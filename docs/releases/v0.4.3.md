# reSOT v0.4.3

Windows demo and retail executables and the shared Android APK use version
0.4.3; Android versionCode is 13. Both targets still require the user's supported
Xbox game files. Game content, logs and compiled packages are not committed.

## Languages

- **Game language: English, French or Spanish (retail).** The supported USA retail
  disc contains all three. The game now starts in the language saved as
  `[Game] Language` in `resot-options.ini`; English is the default on Windows and
  Android. Contributed by GrandaCoder (Camilo Granda), pull request #19.
- **Language in reSOT Options (retail).** A new Language page in reSOT Options
  (main and pause menus) offers English, French and Spanish. The choice is saved
  at once and applies the next time the game starts, because the game reads its
  language when it starts; the label says which one is waiting for the restart.
- **Launchers in English, French and Spanish.** The Windows and Android launchers
  follow the system language when it is one of the three (English otherwise), and
  have a "Game language" button that changes the same setting. Also from pull
  request #19.
- The demo always runs in English: its languages have not been checked.

## Performance

- **Guest memory reads without system calls (Windows, both games).** reSOT's own per-frame checks
  (menus, cheats, the game behaviour options) asked Windows about the memory before
  every word they read. In a heavy retail scene that was 17% of the game thread's
  time. Guest RAM is now read directly, as it already was on Android. Measured on
  the user's PC in that scene: the game thread's work per frame fell from 6.0 to
  4.6 ms.
- **Direct3D 11 and 12: one shader per render state.** Each combiner state is drawn
  with its own straight-line shader, and D3D12 also translates vertex programs.
  D3D12 stutter in effect-heavy scenes was reduced: a pipeline worker kept for
  reference programs, batched visibility reports, the geometry cache and compact
  vertices on D3D12. The user reported excellent performance on D3D11, Vulkan and
  the demo.
- **Fewer render passes.** Full clears become the load operation of the next pass,
  and visibility queries stay inside one pass.
- **Android: big cores and an optional GPU turbo.** Game threads stay off the
  little cores (`RESOT_BIG_CORES=0` turns this off). `GpuTurbo=1` under `[Graphics]`
  holds an Adreno GPU at its top clocks while the game is shown; it is off by
  default and has no launcher row. Neither was tested on a device.

## Experimental: direct renderer

`RESOT_DIRECT_DRAW=1` (off by default, Windows) sends the game's graphics calls to
the renderer as typed operations instead of Xbox GPU commands: draws, render
targets, textures, combiners, state, vertex programs, clears and flips, on both the
demo and retail. The user played inside a demo level and in several retail scenes
with no visible defect. With it on, retail runs 8 submissions ahead of the GPU
thread instead of 1: in a heavy retail scene (about 1,600 draws a frame) the user
saw 82-88 fps against 64 before. Details in `docs/DIRECT-RENDERER.md`.

## Debug views (Windows)

- **F8** cycles the normal view, No lighting, Vertex and Show triggers, with a
  short red label. Show triggers draws the volumes of detection zones, logic
  objects and hidden meshes. Nothing is saved. The user confirmed the views work.

## Android

- **New app icon background**: a square of the launcher's own night-blue ground
  with its rosettes and stars (`tools/icon-background.py`), behind the reSOT logo.

## Tools

- The sampling profiler (`RESOT_PROFILE_MS`) now unwinds frames correctly in the
  GPU driver and names the runtime's internal functions; it also reports time by
  module.

## Known issues and what was not checked

- Retail Magic Fountain teleport: the fade to black does not appear and the camera
  stays on the bridge until the view changes. Long-standing, left open.
- The Language page and the launchers' translations were built but not run. French
  and Spanish game text was not seen in game by the agent.
- Android was not tested on a device for this release: the icon, the language
  selector, big cores and GPU turbo are built only.
- The direct renderer is off by default and was not tried on Android, nor on the
  demo with the latest changes.
- The agent did not run these final builds.
