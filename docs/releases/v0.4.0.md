# reSOT v0.4.0

Windows demo and retail executables and the shared Android APK use version
0.4.0; Android versionCode is 10. Both targets still require the user's supported
Xbox game files. Game content, logs and compiled packages are not committed.

- **Special Load Map.** In reSOT Options on the main menu, on both games.
  The demo lists every map of its BF (20) and sends the title's own Load Map
  message. The retail lists 30 area maps, with the original keys of the BF's
  `WOLInfo.bin`. A map is loaded the way a saved game is: Start New Game only
  closes the menu, then the map is requested with one of its own checkpoints
  and no intro movie, before the balcony scene. 1401 and 8101 are entered at
  1401 Cour and 8101 Bridge Support: loaded without a usable checkpoint, 1401
  Corridor Start and 8101 Tower Base crashed.
- **Built-in cheats switch.** Both games keep their developers' cheats behind a
  variable of the universe AI that no menu set. "Cheats: On/Off" in reSOT
  Options (main and pause menus) and in the Windows F7 panel changes it while
  the game runs.
- **reSOT Options in the pause menu** of both games. The demo hides "Quit to
  Demos Menu" (`RESOT_DEMOS_QUIT=1` brings it back).
- **F7 Game behavior** (Windows): tutorials on or off (retail; also on
  Android) and the dagger.
- **HD menu font.** The menu font sheet of each game (512x128) is enlarged four
  times on the host with sharp edges, so menu text stays crisp at high
  resolutions; every letter keeps its place. Direct3D 12 and Vulkan renderers,
  Windows and Android. `RESOT_HD_FONT=0` keeps the original.
- **Retail 7601 Salle no longer crashes.** The title makes texture pages
  read-only, and the GPU executor then faulted writing to one of them. Those
  pages now keep write access.
- **Prince with a body after a map change.** When a level brings a costume
  that is not loaded, the Prince's set-up now picks a costume that is. Before,
  the Prince showed only his head.
- **Demo E3 logo hidden.** With the reSOT menu entries the "Prince of Persia"
  logo in the corner was drawn partly past the right edge, and the cause was not
  found. Its texture is now drawn transparent (Direct3D 12 and Vulkan).
- **Mali crash on Start Game** (GitHub #8, #9). The Vulkan shaders no longer
  declare SPIR-V extensions that those drivers reject at the first pipeline.
- **Window icon.** The game window's title bar has its own icon.

Not yet validated by a person: the retail Special Load Map on its new path
(no balcony, Prince at the checkpoint) on every map, the HD font on screen,
the Mali devices. Known: four
demo maps (03_GP11_GreatHall_Fight, 05_GP14_E3_Cour, 06_GP24_Bath_Fight,
06_GP24_E3_Long) crashed when requested directly and are not yet checked
through the Load Map message.
