# reSOT v0.4.4

Windows demo and retail executables and the shared Android APK use version
0.4.4; Android versionCode is 14. Both targets still require the user's supported
Xbox game files. Game content, logs and compiled packages are not committed.

Measured by the user on Windows, retail, Vulkan, RTX 3060, 225% internal
resolution, in the same heavy scene (about 1,600 draws a frame): about 64 fps
at the start of 2026-11-02, about 143 fps at the end of this work; an empty
view about 700 fps. Android was
built, not run.

## Performance

- **Direct renderer on by default, on every renderer.** Direct3D 11, Direct3D 12,
  Vulkan and Android: D3D routines of both games hand the renderer typed tokens
  instead of Xbox GPU packets. `RESOT_DIRECT_DRAW=0` returns to the packet path.
  A `RESOT_DIRECT_DRAW` key in `resot-options.ini` is not read.
- **Retail recorded pushbuffers as direct draws.** About two thirds of the retail
  draws came from pushbuffers recorded once and copied whole into the command ring
  on every frame. They are now kept as records the game compares word for word,
  and their draws reuse geometry already on the GPU. Executor time in the heavy
  scene: 8.95 to 6.2 ms a frame.
- **Game and renderer in parallel (retail).** The game may queue 32 submissions
  instead of 8, but stays at most two frames ahead of the renderer
  (`RESOT_FLIP_AHEAD`), and hands each frame over as soon as it flips. With 32
  alone most of the level drew black after some minutes. A one-frame limit fixed
  that but made game and renderer alternate (heavy scene about 84 fps, empty view
  about 400); two frames ran about 33,000 frames with no black level, a longer
  session is still to be checked.
- **Present without a monitor query every frame (Vulkan).** About 13% of the
  renderer thread's time on NVIDIA.
- **Game memory reads without system calls (Windows).** Reads of objects in the
  extended heap, about 10% of the game thread in the heavy scene and 28% in menus.
- **Faster vertex conversion, geometry cache and matrix multiply.** Per-attribute
  checks once per draw (D3D11 and native), cheaper cache slot hashing, and the
  retail D3DX matrix multiply in native code (9% of the game thread to 0.9%).

## Fixes

- **Light halos green or flashing white (retail).** At a raised internal
  resolution the two one-pixel probes behind each halo can count different
  numbers of samples, and the halo's visibility ratio went above 1. It is now kept
  between 0 and 1.

## Launchers

- **Game language only in reSOT Options.** The Windows and Android launchers no
  longer show the "Game language" button; the language is chosen on the Language
  page of reSOT Options (retail), saved as before in `[Game] Language`.

## Not checked

- Android: built only, not installed or run.
- The demo: built only; it has the direct renderer by default but keeps its
  synchronous KickOff and the lifted matrix multiply.
- Direct3D 11 and Direct3D 12 were not run with the last changes.
- The halo fix, the kick at the flip and the hidden launcher button were built,
  not yet seen.
