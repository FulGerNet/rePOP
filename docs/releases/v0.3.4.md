# reSOT v0.3.4

Windows demo and retail executables and the shared Android APK use version
0.3.4; Android versionCode is 9. Both targets still require the user's supported
Xbox game files. Game content, logs and compiled packages are not committed.

- **A pipeline the driver rejects no longer closes the game.** Android reports
  from Mali GPUs (GitHub #8 Helio G96 / Mali-G57, #9 Exynos 2100 / Mali-G78)
  end in SIGABRT about a second after Start Game, the shape of the renderer's
  abort when one graphics pipeline fails to compile. Such a draw now retries
  the reference shaders and is skipped (counted in the log) only if those are
  rejected too; host blits and clears still require theirs. Not yet confirmed
  on those devices: their diagnostic archives did not include the game logs.
- **D3D's wait for a lagging GPU is released when the executor has caught up.**
  When D3D believes the GPU is 0x2400 bytes behind a fence it patches a
  NO_OPERATION 5 interrupt into commands it already submitted, then waits for
  that interrupt. The executor can already be past them, so the interrupt never
  came. The wait is now also released once everything submitted has been
  consumed. Both targets (event `device+0x1DCC` on retail, `+0x1DBC` on the demo).
- **Demo KickOff stays synchronous.** The retail asynchronous KickOff was tried on
  the demo: with 4 or 16 submissions ahead its first level drew almost black,
  with 1 it was correct but slower than synchronous. The demo keeps the
  synchronous KickOff; `RESOT_KICK_AHEAD` still enables it for testing.
- **Definitive logo.** `docs/media/reSOT_logo.png` is the README logo, the app
  icon on Windows and Android, and the top of both launchers. The Android icon
  is adaptive: the logo in the safe zone over the launcher's night-blue
  ornament, so round, squircle and square masks never cut it. Under it the
  launchers show the Prince of Persia title, whose sand cloud moves behind still
  letters and sheds grains, then "the sands of time" and a "Recompiled" badge.

Not addressed: the constant flickering on Galaxy S25 / S25 Ultra (GitHub #7)
needs a log or recording from those devices. Not yet validated by a person: the
Mali devices, the Android launcher on screen.
See [VALIDATION.md](../VALIDATION.md) for commands and results.
