# reSOT v0.3.3

Windows demo and retail executables and the shared Android APK use version
0.3.3; Android versionCode is 8. Both targets still require the user's supported
Xbox game files. Game content, logs and compiled packages are not committed.

- **Asynchronous KickOff (retail).** The title used to wait in every KickOff
  until the GPU executor had executed the previous segment and presented, so
  the two ran in series. It now clears the write-combining flush bit itself and
  runs up to 16 submissions ahead; GET still advances only after a scan, and
  the fence mirror is paired with the PUT it belongs to. `RESOT_KICK_AHEAD=0`
  restores the old behaviour. Scripted Windows Vulkan run: menu 174-221 to
  226-275 fps, first level 134-192 to 177-216 fps. The demo keeps the
  synchronous KickOff until it is checked on its own XBE.
- **Retail mid-game freeze.** When the GPU is far behind a fence, retail
  BlockOnFence inserts NO_OPERATION 5 and waits on an interrupt-set event and
  on PGRAPH 0x400B10; neither was modelled, so the title could stop for good
  while audio kept playing (Android log, chapter 25, `2501_GearRoom`). The
  executor now sets that event and mirrors the register. Not yet replayed at
  the places where it froze.
- **Audio crackle.** Clock drift between the emulated APU and the sound device
  used to clear the Android output queue or drop frames on Windows, and pad
  silence when it ran dry. The output rate now follows the queue depth by at
  most 0.8% on both hosts.
- **Android calls.** The lifted routines in the game library call each other
  directly (`-Bsymbolic-functions`) instead of through the PLT; they stay
  exported for crash reports.
- **New logo and icons.** The new reSOT logo replaces the old one in the README,
  the app icons and both launchers, where the sand around the letters streams
  and sheds grains. The previous logos and icons are kept in `docs/media`.

Not yet validated by a person: Android gameplay frame rate with this build, the
former freezing places, listening for crackle, the demo with these changes.
See [VALIDATION.md](../VALIDATION.md) for commands and results.
