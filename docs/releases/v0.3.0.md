# reSOT v0.3.0

reSOT continues to advance as a playable native port of the Xbox retail game
and E3 2003 demo of Prince of Persia: The Sands of Time for Windows and
Android. The user reports good gameplay on both platforms in tested configurations.

## Highlights

- Restored retail music streaming. Main-menu music is confirmed working
  again on Windows after restoring the original completion ordering.
- Fixed the demo's Load Map and reSOT Options entries disappearing when
  the main menu is rebuilt.
- Hidden Xbox Live in the retail pause Options page as well as the main menu.
- Added mouse and touch selection for native menu rows, while retaining
  keyboard and physical-controller navigation.
- Improved Android's contextual touch controls:
  - FPS stays visible and usable when the gameplay pad is hidden, including
    in menus and cutscenes. While the FPS panel is open, the button becomes
    invisible to keep the text clear; tapping its usual position closes the panel.
  - The overlay toggle fades out after a tap or automatic hiding. Its
    invisible touch area remains active, so the full controls can be restored.
  - Matching Back and right-arrow Confirm buttons appear at the bottom
    corners of menus and cutscenes while the full pad is hidden.
  - Reopening the full pad hides the corner buttons. Scene changes clear
    held input and restore the appropriate layout without replacing the
    player's saved gameplay visibility preference.
- Improved Vulkan efficiency with shader and material caching, exact
  geometry reuse, batched command payloads and texture-upload optimizations.
- Included retail fountain-return and ultrawide HUD corrections, along with
  further RGB565 alpha and shadow-projection fixes.
- Improved Android audio queue recovery and display/thermal frame budgets.
- Refined touch artwork and diagnostics, and refreshed the README with
  corrected UTF-8 text and a clearer feature-status overview.

## Packages and validation

Windows provides separate demo and retail executables. One Android arm64
APK includes both targets. The version remains **0.3.0** (Android versionCode 5).
Your own supported Xbox game files are required.

Windows and Android builds and the recorded shader, pointer, audio and GPU
checks pass. The latest Android overlay visibility/fade policy also passes
host Java regression checks. On-device interaction for this final overlay
update remains unverified; gameplay music after the streaming restoration,
complete save persistence and remaining visual effects still need broader
validation. See [the validation log](../VALIDATION.md).
