# reT2T

Placeholder for the planned static recompilation of the original Xbox version of
**Prince of Persia: The Two Thrones** into a native Windows executable.

Part of [rePOP](https://github.com/FulGerNet/rePOP), on the `reT2T` branch.

**Status: placeholder only.** No implementation or playable build is available.

This project does not include game files, extracted assets, or generated game
code. Any future recompilation will require files from your own copy of the game.

For The Sands of Time project, see
[reSOT](https://github.com/FulGerNet/rePOP/tree/reSOT).
